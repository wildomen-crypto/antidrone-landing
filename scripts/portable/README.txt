ТОПИНЖЕНЕР — ПЕРЕНОСИМАЯ ВЕРСИЯ САЙТА

Для Windows 10/11, 64-бит. Нужен обычный современный браузер.
Устанавливать Node.js, npm, Git или другие средства разработки не нужно.

1. Скопируйте ZIP на другой компьютер.
2. Распакуйте ВСЮ папку архива в удобное место, например в Документы.
3. В распакованной папке дважды щёлкните START.cmd.
4. Сайт откроется в браузере автоматически. Если не открылся, скопируйте
   адрес из окна запуска в адресную строку браузера.

Не запускайте START.cmd прямо внутри ZIP. Не перемещайте папку во время работы.
Оставьте окно запуска открытым. Для остановки нажмите в нём Ctrl+C.
При занятом порте 3100 автоматически выбирается следующий свободный.
Права администратора и доступ к интернету для работы сайта не нужны.
Ссылки на внешние сайты и телефон/email требуют соответствующих программ/сети.

ЗАЯВКИ
Новые заявки сохраняются только на этом компьютере в папке data.
LEADS.cmd показывает список и создаёт там JSON с контактами и схемами.
Чтобы перенести заявки, остановите сайт и скопируйте всю папку data.
Не удаляйте эту папку, если хотите сохранить заявки.
Старые заявки и локальные настройки исходного ПК в архив не включены.
Отправка заявок в email/CRM не настроена; сайт подтверждает сохранение в локальной БД.

СОСТАВ
app — готовый сервер, зависимости, страницы и все изображения.
runtime — официальный Node.js и npm для Windows x64, с лицензиями.
source — полный исходный код сайта и документация для дальнейших изменений.
licenses — лицензии используемых библиотек.
manifest.json — состав, версии и контрольные суммы файлов сборки.
data создаётся при первом запуске и хранит новые заявки.

Редактирование source не меняет готовый app автоматически: нужна новая сборка.
Для разработки можно использовать runtime/node.exe и runtime/npm.cmd;
зависимости source устанавливаются по package-lock.json (для этого нужен интернет).
Обычный запуск START.cmd уже полностью готов и ничего не скачивает.

Цена проекта — предварительная оценка по 1250 ₽/ч и выбранным КМ/КМД/КЖ.
Ставки и коэффициенты трудоёмкости требуют уточнения владельцем проекта.
Изображения материалов и объектов — созданные визуализации.
Пакет запускает сайт локально; публичное размещение требует отдельной настройки.
