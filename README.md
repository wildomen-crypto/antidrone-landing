# Лендинг защитных металлоконструкций

Отдельный проект для разработки по ТЗ. Начальная версия B01.1 содержит
минимальную русскоязычную страницу и инфраструктуру разработки.
Полный лендинг, калькуляторы, 3D, цены и сохранение заявок ещё не реализованы.

B01.2 добавляет общие данные компании и каталог в коде. На минимальной
странице уже используются название, телефон и email из конфигурации.
Карточки каталога и полный лендинг будут реализованы в B02.1.

## Запуск в Windows PowerShell

Требуется Node.js >=20.9.0 и npm. Проверенная локальная среда:
Node.js 24.13.1, npm 11.8.0. Использовать `npm.cmd`, если PowerShell
ограничивает запуск `npm.ps1`.

```powershell
Set-Location C:\taran\antidrone-landing
npm.cmd ci
npm.cmd run dev
```

Открыть http://127.0.0.1:3100. Сервер слушает только этот компьютер.
Если порт занят, перед новым запуском проверить существующий процесс.
Для другого порта: `npm.cmd run dev -- --port 3101`.

## Проверка и собранная версия

```powershell
npm.cmd run typecheck
npm.cmd run build
npm.cmd run start
```

`typecheck` сначала генерирует определения маршрутов через `next typegen`,
поэтому работает и в свежей копии без готового каталога `.next`.
`npm.cmd run check` последовательно выполняет типизацию и сборку.
Перед `start` нужна успешная сборка; `dev` и `start` не запускать
одновременно на одном порту. Остановка своего сервера — Ctrl+C.

## Требования и порядок работы

- `docs/SPEC.md` — требования к продукту.
- `docs/RESEARCH.md` — источники и конструктивные референсы.
- `docs/CODEX_PLAN.md` — 12 этапов, 32 блока, протокол восстановления.
- `docs/BLOCKS.md` — состояния блоков.
- `docs/STATUS.md` — текущий результат и следующий шаг.
- `docs/checkpoints/` — карточки выполнения.
- `AGENTS.md` — постоянные правила для Codex.

Один запрос на выполнение охватывает один блок. При возобновлении
сначала читать `STATUS.md`, карточку текущего блока и фактический diff.
Не удалять незавершённые изменения и не переинициализировать проект.

Зависимости зафиксированы точными версиями и `package-lock.json`.
TypeScript 5.9.3 выбран как совместимая стабильная линия для базовой
настройки Next.js; обновление до другого major — отдельная проверка.
3D и дополнительные библиотеки подключаются в соответствующих блоках.

## Данные компании и каталог

- `config/company.ts` — единственное место редактирования контактов.
  Переносить значения с topengineer.ru/contact, затем обновлять
  `verifiedAt`. Адрес клиентского офиса и юридический адрес разделены.
  Реквизиты опубликованного ООО не назначают автоматически оператора
  формы; `formOperator` заполняется после выбора стороны договора.
- `config/catalog.ts` — C1–C8, M1–M8, W1–W3 и шесть несущих систем.
  `release` определяет очередь реализации, а не готовность изделия.
  Все калькуляторы пока planned. Материалы требуют проверки инженером,
  стеновые модули — подтверждения поставки.
- `compatibility.approved` пока пуст. Это отсутствие согласованных
  сочетаний, а не разрешение всех сочетаний. Утверждённая запись должна
  включать форму, материал, систему, шаблон, автора и дату проверки.
- `lib/configuration/schema.ts` — версия 1, единицы m/m2/kg, допустимые
  ID и union конфигураций. Для C5–C7 параметры зависят от варианта.
  Контуры C8 ограничены 1–3 на уровне типов. ViewerState не входит в
  заказ, поэтому скрытие элемента не означает исключение из комплекта.
- `tests/configuration/contract.typecheck.ts` — статические проверки
  контракта. Неверные смешанные размеры и контуры не должны компилироваться.

TypeScript проверяет код разработчика. Проверка внешнего JSON, чисел,
проёмов и размеров во время исполнения будет добавлена в B03.1.
Пока нет подтверждённых тарифов, регионов монтажа, SLA и гарантий:
их нельзя получать из пустых полей или придумывать для интерфейса.
Справка по исходной настройке: [Next.js installation](https://nextjs.org/docs/app/getting-started/installation).

Локальная версия закрыта от индексации через metadata. Публикация и
юридические документы предусмотрены поздними блоками. Git хранит код,
не секреты и не БД заявок; резервирование этих данных настраивается отдельно.
