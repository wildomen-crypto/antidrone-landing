Отдельная страница «Антидроновая защита» для Joomla 3.10.12 / yoo_monday

1. В панели Joomla: Расширения → Менеджер расширений → Установить.
   Загрузите этот ZIP целиком. PHP и Node устанавливать дополнительно не нужно.
2. В менеджере модулей откройте «Антидроновая защита — 3D и проектирование».
   Опубликуйте, заголовок — скрыть, позиция — antidrone-protection,
   назначение — только пункт меню нужной страницы. Кэширование — отключено.
3. В материале страницы вставьте {loadposition antidrone-protection}.
   Должен быть включён стандартный плагин «Контент — Загрузка модулей».
   Старое содержимое и заголовок материала уберите по вашему выбору.
   Исключите страницу из полного кэша страниц: токен формы связан с сеансом.
4. Проверьте страницу на компьютере и телефоне. Модуль использует шрифты и
   CSS установленного шаблона, без второй шапки и подвала. Не вставляйте
   iframe вручную в редактор: его создаёт модуль.
5. По умолчанию приём заявок выключен. Для реальной отправки настройте почту
   в общих настройках Joomla, проверьте тестовое письмо, укажите получателя
   в модуле и включите приём заявок после согласования условий обработки данных.
   Приложенные страницы согласия/политики пока содержат черновые условия.
   Формы отправляют почтой Joomla, без отдельной базы заявок и без Node-сервера.
   Повтор одной заявки в пределах сеанса не отправляет второе письмо;
   ограничение — пять попыток за десять минут на сеанс. Это не общий антиспам.
6. Конфигурация прикладывается к письму как JSON. Цена приблизительная:
   1250 ₽/ч по черновой оценке трудоёмкости КМ/КМД/КЖ. Приём SMTP не означает,
   что письмо гарантированно доставлено во входящие; проверяйте почту получателя.

Путь ресурсов: /media/mod_antidrone_design/app/. Сборка рассчитана на Joomla
в корне домена topengineer.ru. Для CMS в подпапке нужна отдельная сборка.
Установка проверена по структуре ZIP и API Joomla 3.10.12; реальная панель
хостинга и её SMTP без доступа к администратору не проверялись.
Исходники и описание: репозиторий antidrone-landing, папка joomla и /joomla.
Лицензии встроенных открытых библиотек находятся в licenses.
Лицензионный шаблон YOOtheme не включён в ZIP — используется существующий.
