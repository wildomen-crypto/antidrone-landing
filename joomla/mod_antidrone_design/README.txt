Антидроновая защита — Joomla 3.10.12 / yoo_monday, версия 1.1.0

1. Расширения → Менеджер расширений → Установить: загрузите ZIP целиком.
   Новый архив обновляет модуль 1.0.0. Дополнительный Node не нужен.
2. Опубликуйте модуль «Антидроновая защита — 3D и проектирование».
   Заголовок скрыть; позиция antidrone-protection; назначение только нужной
   странице. Кэширование модуля выключить.
3. В материале вставьте {loadposition antidrone-protection}; включите плагин
   «Контент — Загрузка модулей». Старое содержимое и повторный заголовок убрать.
4. Сохраните существующие скрипты сайта и /upload.php. «Использовать форму сайта»
   включено по умолчанию. Модуль использует jQuery сайта и существующий обработчик
   компании. Новый SMTP/получатель не нужны; исходные формы не меняются.
5. Проверьте компьютер/телефон и отправку после установки. Без jQuery новые
   формы блокируются. Телефон или email обязательны, имя необязательно,
   согласие обязательно. Вместе с формой конструктора передаются разделы,
   примерная рублёвая цена и все параметры 3D в комментарии. Нижняя форма
   передаёт описание без схемы. Загрузка файлов не добавлена.

Отправка повторяет GET-протокол custom.js: DATA[NAME], DATA[PHONE_WORK],
DATA[EMAIL_WORK], DATA[COMMENTS], files_data и submit. Длинное описание нужно
сократить: данные не обрезаются. Повтор в текущей вкладке не отправляет вторую
заявку; при неизвестном результате связи автоматического повтора нет.
Успешный ответ соответствует подтверждению исходной формы; фактическую доставку
проверяйте по получателю. /upload.php уже есть на хостинге и не входит в ZIP.

Ресурсы: /media/mod_antidrone_design/app/. Joomla должна быть в корне домена.
Шрифты/CSS берутся из установленного шаблона; повторной шапки/подвала нет.
Лицензии — licenses. YOOtheme не включён. Юридические тексты — черновики,
цена — предварительная. GitHub Pages не отправляет заявки компании.
Проверки проводятся локально без настоящих писем; доступ к панели/почте
реального topengineer.ru не предоставлялся. Описание: docs/joomla.md.
