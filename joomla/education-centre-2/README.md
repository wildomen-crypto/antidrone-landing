# Отдельная страница учебного центра

Адрес: https://topengineer.ru/education-centr-2.
Опубликовано 7 октября 2026: материал 705, существующее меню 1342.
Обычный статический материал Joomla 3.10.12. Он не собирает анонсы.
Используются Bootstrap Grid и Open Sans уже установленного yoo_monday.
Весь дополнительный CSS ограничен блоком `#te-education-2`.
Шапка, подвал, шаблон, обработчик заявок и исходные статьи не редактируются.

## Что хранится в папке

- `article.html` — понятный исходник содержимого: заголовки, тексты, ссылки.
- `education.css` — оформление только нового содержимого.
- `assets/*.webp` — две сгенерированные иллюстрации занятий.
- `joomla-ready.html` — готовое содержимое одного материала: CSS и обе
  фотографии встроены. Дополнительная загрузка файлов на сервер не нужна.
- `build-article.cjs` — обновление готового HTML после изменения исходников.
- `design-qa.md` — результаты визуальной проверки.

Воспроизведение готового HTML: `node joomla/education-centre-2/build-article.cjs`.
Для локальной проверки с настоящей оболочкой сайта:
`node tests/joomla/education-serve.cjs`, затем
http://127.0.0.1:3154/education-centr-2.
Локальная оболочка хранится отдельно в игнорируемой `.local`.
Формы в локальной проверке не отправляются; кнопки программ ведут на сайт.

## Настройка Joomla

1. Создать обычный материал, категория «Не указано» (ID 2), доступ Public,
   язык «Все». Категория «Обучение» не используется, чтобы новый материал
   не добавлялся девятым анонсом на исходную страницу учебного центра.
2. Вставить `joomla-ready.html` в редактор без визуального преобразования.
3. Скрыть заголовок Joomla, автора, даты, категорию, теги, счётчик просмотров,
   навигацию и иконки. Заголовок страницы уже находится внутри содержимого.
4. Для отладочной страницы установить `noindex, follow` только в метаданных
   этого материала.
5. У существующего пункта меню ID 1342 изменить тип «Блог категории» на
   «Материал», выбрать этот новый материал. Сохранить заголовок
   «Учебный центр 2», алиас `education-centr-2`, порядок, меню, родителя,
   шаблон и доступ. Новые пункты в общей шапке не добавлять.
   В параметрах материала этого пункта меню тоже скрыть заголовок Joomla.

Фотографии показывают вымышленные учебные сцены. Иллюстрации программ и
все восемь адресов курсов взяты из действующей страницы учебного центра.
Два формата проектирования КМ/КМД/КЖ ведут на одну существующую статью.
Кнопка подбора курса ведёт на действующую страницу контактов.

Ограничение отладочного варианта: встроенные изображения увеличивают HTML
до примерно 377 КБ. При дальнейшем развитии их можно вынести в отдельные
файлы без изменения расположения блоков.
