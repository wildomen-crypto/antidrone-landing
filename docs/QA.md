## Проверка хранения и отказов

Unit-тесты подтверждают транзакцию lead+outbox, неизменный ID при повторе,
запрет изменения тела с прежним ключом, повтор уведомления после сбоя,
лимит запросов, удаление истёкших данных и зависимой очереди, резервный
снимок SQLite и integrity_check. Восстановленный снимок читается отдельно.

API проверен на 201/200/409/400/403/413/429/503. Отдельный временный сервер
с недоступным каталогом базы не возвращает saved:true. SITE_PUBLIC=true
при неутверждённых документах закрывает форму. Реальный внешний получатель
не подключён; доставку SMTP/CRM нельзя считать проверенной.

При QA обнаружено несовпадение внутреннего localhost URL Next с адресом
127.0.0.1 в браузере. Проверка origin исправлена: локально сверяется Host
с разрешёнными локальными адресами, публично требуется SITE_ORIGIN.

## Производительность и ограничения

3D загружается при приближении к viewer. Повторяемые элементы и модули
инстанцируются; сетки используют текстуры; rendering запускается по
изменениям, DPR ограничен 1,5. Геометрия ограничена 12 000 элементами.
Текстуры, геометрии и OrbitControls очищаются при смене состояния.

Проверка heap — диагностический тест браузера, не доказательство отсутствия
любых утечек GPU и не измерение на реальном телефоне. Safari/iOS, Android,
Firefox, внешний HTTPS, доставку получателю и производственный сервер
нужно проверить отдельно.

Крупные детали — типовые учебные схемы, сечения и основания условны.
Стеновые модули отображаются и учитываются геометрически; раскладка
производственных изделий, крепёж, профили, масса и прочность требуют проекта.
Печатная карточка не является автоматически сформированным договорным КП.
