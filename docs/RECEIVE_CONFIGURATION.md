# Получение конфигураций

Кнопка «Получить расчёт» скачивает файл topengineer-C*.json без контактных
данных и прикрепляет ту же конфигурацию к форме. В браузере сохраняется
черновик: после обновления основной страницы модель и вложение восстановятся.
Контактные данные в этот черновик не входят.

После заполнения контакта, согласия и нажатия «Отправить заявку» сервер
сохраняет конфигурацию вместе с заявкой в SQLite. Успешная запись подтверждается
номером заявки. До отправки формы конфигурация находится в файле/браузере,
а на сервере ещё не зарегистрирована. После успеха черновик очищается.

В корне проекта на сервере посмотреть номера сохранённых заявок:

```powershell
npm.cmd run leads -- list
```

Выгрузить только конфигурацию без контактов, подставив номер заявки и
свой путь в существующем частном каталоге:

```powershell
npm.cmd run leads -- configuration НОМЕР_ЗАЯВКИ C:\taran\private\configuration.json
```

Для выгрузки всей заявки используется команда export с такими же аргументами.
Файлы не размещать в public; существующий файл команда не перезаписывает.
Конфигурация содержит размеры, материалы, несущие элементы, основания,
стороны, проёмы, контуры и выбранные работы.

Автоматическая доставка в email/CRM сейчас не подключена. Для неё нужен
настроенный получатель; сохранение в SQLite и частная выгрузка работают
независимо. Публичный запуск формы выполняется по docs/OPERATIONS.md.
