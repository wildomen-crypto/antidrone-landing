# Отдельная версия для topengineer.ru

`/joomla` использует общий конструктор, изображения, две формы и цену в рублях.
Встроенная версия не повторяет шапку, подвал и контакты родительского сайта.
Основная версия и её серверный API сохранены.

05.10.2026 проверены указанная страница и публичный manifest: Joomla **3.10.12**,
шаблон **yoo_monday**, Open Sans, серые заголовки, оранжевые кнопки, jQuery 1.12.0.
React/Three работают в iframe своего домена, родитель передаёт оформление
и ссылки на CSS. Лицензированный YOOtheme не копируется в архив.

## Сборка и установка

`npm run build:joomla` создаёт установочный ZIP в Downloads: PHP-модуль,
готовую страницу, изображения, JavaScript, CSS, инструкцию и лицензии.
Node и SQLite на хостинге не нужны. Joomla должна находиться в корне домена.

1. Расширения → Менеджер расширений → Установить → загрузить ZIP.
   Версия 1.1.0 обновляет модуль 1.0.0.
2. Опубликовать модуль «Антидроновая защита — 3D и проектирование», скрыть
   заголовок, позиция `antidrone-protection`, назначение только нужной странице.
3. В материале разместить `{loadposition antidrone-protection}`. Включить плагин
   «Контент — Загрузка модулей». Убрать старое содержимое и повторный заголовок.
   Сохранить скрипты и обработчик существующего сайта.
4. «Использовать форму сайта» включено по умолчанию. Проверить компьютер/телефон.
   Высота iframe и переходы к конструктору автоматические.

## Существующая отправка

В публичном `templates/yoo_monday/js/custom.js` обработчики `submitTopForm` и
`submitPopupForm` вызывают **jQuery.ajax GET `/upload.php`**, несмотря на POST
в HTML. Поля: `DATA[NAME]`, `DATA[PHONE_WORK]`, `DATA[EMAIL_WORK]`,
`DATA[COMMENTS]`; также `files_data` и `submit`.

Обе новые формы передают эти же поля родительскому мосту. Он использует
**уже загруженный jQuery сайта и тот же `/upload.php`**. Получатель и отправка
остаются в существующем обработчике компании; новый SMTP/получатель в модуле
не нужны. Исходные формы, значения, обработчики и файлы не меняются.
Старый custom.js целиком не копируется и не запускается повторно.

Имя необязательно, нужен хотя бы телефон или email; контакты проверяются.
В комментарий добавляются тип конструкции, разделы КМ/КМД/КЖ, опоры, заполнение,
приблизительная цена и полный JSON параметров 3D. Нижняя форма без схемы
отправляет контакты/описание. `files_data` пуст: загрузка файлов не добавлена.
Согласие обязательно; юридические страницы остаются ранее созданными черновиками.

Мост принимает сообщения только от собственного iframe своего домена; endpoint
закреплён в PHP. Повтор одной заявки в текущей вкладке не вызывает второй запрос.
При подтверждённой HTTP-ошибке можно повторить; при тайм-ауте/обрыве автоматического
повтора нет, так как результат неизвестен. Это не серверная защита от спама
или дублей между вкладками/после перезагрузки.

Сохранён GET-протокол оригинального скрипта: данные находятся в URL запроса.
Слишком длинный URL отклоняется с просьбой сократить описание, поля сохраняются.
Подтверждение соответствует оригиналу — успешный HTTP-ответ; явно возвращённые
JSON-ошибки дополнительно отклоняются. Номер заявки не выдумывается.
Ответ обработчика не доказывает доставку письма во входящие.

Прежний `com_ajax` helper оставлен для совместимости с архивом 1.0.0;
новый модуль его не вызывает. Обычная Next-версия продолжает `/api/leads`.
GitHub Pages — демонстрация: обе формы не отправляют данные никуда.

## Проверки и ограничения

`npm run check`: типизация, тесты геометрии/цен/контактов/транспортов, сборка.
Тесты моста проверяют поля, цену, JSON, оба варианта формы, ошибки, повторы,
чужой origin/source и длину URL. `tests/joomla/serve.cjs` — локальный стенд
с jQuery 1.12.0 и CSS сайта; его `/upload.php` ничего не пересылает компании.
`/__fixture/requests` показывает локальные запросы; эти маршруты не входят в ZIP.
PHP проверяется на 7.4.33; старый helper имеет отдельные контрольные примеры.

Без доступа к панели Joomla установка на живой хостинг и фактическая доставка
новой заявки остаются проверкой после установки. Коммерческая страница автоматически
не изменяется. Серверный PHP `/upload.php` публично не виден; его внутренние
правила известны только владельцу сайта.

и https://topengineer.ru/proektirovanie/proectirovanie-antidronovoi-zashiti.
