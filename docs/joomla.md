# Отдельная версия для topengineer.ru

Вариант `/joomla` использует общий конструктор, каталог, изображения, формы
и черновую цену в рублях. Основная версия сайта сохраняется. Встроенный вариант
не выводит вторую шапку, подвал, мобильную панель и повторные контакты:
они уже есть на родительском сайте.

05.10.2026 проверена указанная пользователем страница
https://topengineer.ru/proektirovanie/proectirovanie-antidronovoi-zashiti.
Публичный `administrator/manifests/files/joomla.xml` сообщает Joomla **3.10.12**.
Сайт использует шаблон **yoo_monday**, Open Sans, серые заголовки и оранжевые
кнопки. Его jQuery 1.12.0 и старый Bootstrap работают в родительском документе.
React/Three работают в iframe того же домена, поэтому старые скрипты не меняют
внутренние элементы конструктора. Родитель передаёт шрифты, цвета и ссылки
на свои CSS; лицензированный шаблон YOOtheme не копируется в ZIP.

## Сборка и установка

`npm run build:joomla` на Windows создаёт установочный ZIP в Downloads.
В комплекте PHP-модуль, готовая статическая страница, изображения, JavaScript,
CSS, README.txt и лицензии. На сервере остаются только Joomla/PHP и обычная
раздача статических файлов; отдельный Node-процесс и SQLite не нужны.
Модуль рассчитан на CMS в корне домена, как на topengineer.ru.

1. В Joomla: Расширения → Менеджер расширений → Установить → загрузить ZIP.
2. Опубликовать модуль «Антидроновая защита — 3D и проектирование».
   Скрыть заголовок модуля; позиция `antidrone-protection`, назначение только
   пункту меню нужной страницы; кэширование модуля выключено.
3. В материале разместить `{loadposition antidrone-protection}`. Включить
   стандартный плагин «Контент — Загрузка модулей». Это позволяет обойтись
   без вставки iframe в текстовый редактор. Старое содержимое материала
   и его повторный заголовок убрать при установке новой страницы.
4. Исключить эту страницу из полного кэша страниц: токен формы связан с сеансом.
5. Проверить страницу на компьютере и телефоне. Высота iframe меняется
   вместе с содержимым; ссылки выбора конструкции возвращают к конструктору.

## Заявки

По умолчанию отправка отключена. Модуль показывает это возле обеих форм.
Для включения указать получателя в модуле, настроить и проверить почту Joomla,
согласовать условия обработки данных и включить параметр приёма заявок.
Приложенные страницы согласия/политики пока являются черновиками.
Публичная демонстрация GitHub Pages всегда показывает режим просмотра
и не отправляет данные, независимо от почтового модуля.

Транспорт — стандартный Joomla 3 `com_ajax`, метод `submitAjax` класса
`ModAntidroneDesignHelper`. Проверяются POST, токен JSession, доступность
и параметры опубликованного модуля, согласие, контакт и исходные размеры.
Получатель задаётся администратором, не посетителем. Конфигурация прикладывается
к письму как JSON; клиентская цена не считается подтверждённым предложением.
Пять попыток за десять минут на сеанс; повтор одинакового запроса в сеансе
возвращает прежний результат без второго письма. Общего ограничения по IP
или базы заявок нет. Успех означает принятие письма почтовым механизмом Joomla,
а не гарантию доставки во входящие. Ошибка почты не создаёт квитанцию успеха.

## Проверки и границы

`npm run check` проверяет основной сайт, вычисления и оба транспорта форм.
`tests/joomla/helper.php` — локальные примеры PHP с заменой SMTP/БД:
отправка, схема, повтор, ошибочные данные, токен, доступ, лимит и отказ почты.
Не отправляет настоящих писем. Проверен также вызов helper через неизменённый
официальный `components/com_ajax/ajax.php` из Joomla 3.10.12 на PHP 7.4.33.
Это проверка диспетчера с имитацией сервисов Joomla, а не полноценная CMS.
`tests/joomla/serve.cjs` показывает локальное встраивание собранного модуля
со стилями yoo_monday, jQuery 1.12.0 и Bootstrap исходного сайта.

Установочный ZIP и manifest проверены. В браузере проверяются наследование
оформления, авто-высота, варианты C1–C8, пересчёт и мобильная форма.
Доступа к панели и SMTP реального topengineer.ru нет. Установка, почтовая
доставка и сочетание с остальными плагинами конкретного хостинга там
остаются проверкой после установки. Живую страницу автоматически не изменяем.
