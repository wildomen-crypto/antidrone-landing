## Резервная копия и откат

Исходные записи целевого меню и статьи сохранены на сервере вне корня сайта:
в /www/article-backups/antidrone-20261005-*/state.json. Копия включает beforeMenu
и protectedArticle. Здесь также лежит фиксированный установочный архив.
Не переносите эту служебную папку в публичный Git или в корень сайта.

Для отката через панель Joomla:

1. В пункте меню 1338 вернуть тип «Отдельный материал» и выбрать статью 33
   «Разработка КМ». Восстановить только его прежние параметры из beforeMenu.
2. Снять с публикации статью 701 и модуль 419. Статью 33 не редактировать.
3. Обновить кэш меню/модулей/материалов и проверить целевую страницу и /proektirovanie/km.

Не удаляйте весь раздел проектирования, общий шаблон или чужие расширения.
Временный инструмент установки удаляется после проверок; постоянного
доступного из сети инструмента администрирования в проекте нет.

Существующий обработчик отправляет данные в CRM, но не возвращает результат
создания записи. Форма, как и оригинальная форма сайта, подтверждает успешный
HTTP-ответ. Получение компанией новой заявки пока не проверено; без отдельного
разрешения тестовая запись в CRM не создаётся. Публичные GitHub Pages остаются
демонстрацией без отправки. Юридические тексты остаются ранее подготовленными черновиками.
