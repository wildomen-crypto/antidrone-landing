# UI-DENSE-OPTIONS

Статус: VERIFIED. База e712159; предыдущий проверенный код ea2871d.
Ветка ui/dense-options-default-opening. Область: текущий /compact.
Запрос: сечение/основание/стороны в одну строку при достаточной ширине;
передний проём по умолчанию; меньше вертикальных отступов карточек;
несущие элементы выше заполнения стен. /wide и / для сравнения сохранены.

Файлы: Calculator.tsx, app/responsive.css, профильные browser QA,
README/SPEC/QA/STATUS/BLOCKS и эта карточка.
Решение: гибкий ряд групп на средних/малых окнах, перенос только когда
ширины не хватает; иконки 32×32 сохранены. Новая схема с доступным
передним заполнением и допустимым размером проёма начинает с проёмом;
импорт сохраняет выбор пользователя. Плотнее внешние/внутренние отступы
типов/материалов, размеры рисунков сохранены. Порядок DOM: несущие,
стены, кровля, работы. Геометрический алгоритм и JSON-контракт неизменны.

Критерии: 320–2560 px без переполнения/обрезанных названий, группы в один
ряд если помещаются; C1–C8 без ошибок, передний проём виден и уменьшает
ведомость, отключение/импорт сохраняются; порядок рядов, resize/touch/SVG.
Build и responsive/compact browser QA; визуальный просмотр 3 компоновок.
Результат: все три группы на одной линии на среднем/390/600; на 320/360
перенос целой группы по доступной ширине. C4 размеры 232,3 px средний,
316,3 px на 390/600 вместо прежних 285,3/369,3 px. Иконки 32×32.
Типы/материалы с меньшими падингами, картинки не уменьшены дополнительно.
Порядок DOM несущие/стены/кровля/работы. Начальный проём виден в 3D,
ведомость 179 м² вместо 188 м²; выключение/импорт false работают.
Клиентские выборы типа (иконки и каталог) используют общий обработчик,
автовключение не применяется при неподдерживаемой форме/размерах/сторонах.
Build с типизацией/worker, 8 responsive + 5 compact групп PASS, 12 окон.
Resize/touch/C1–C8/JSON/печать/Canvas/SVG, без ошибок JS/overflow.
