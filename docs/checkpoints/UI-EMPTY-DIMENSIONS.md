# UI-EMPTY-DIMENSIONS

Статус: VERIFIED. База 709f5ff. Ветка ui/full-width-empty-dimensions.
Запрос: если параметры отсутствуют (навес/купол), использовать свободную
ширину размеров и уменьшить высоту; дополнительный запрос: у навеса
полностью скрыть неактивный выбор стен. Область: текущий /compact.
Файлы: Calculator.tsx, app/responsive.css, профильный QA,
README/SPEC/QA/STATUS/BLOCKS и эта карточка.
Решение: явный признак наличия параметров; средняя компоновка без них
растягивает размеры в обе колонки, ползунки в 3–5 колонок, группы
сечения/основания справа. Телефон использует две колонки при достаточной
ширине; на 320 сохранить читаемость. При появлении параметров вернуть
обычную компоновку. Неприменимые стеновые карточки не рендерить.
Критерии: C3/C7 ширина на всё место и примерно половина высоты на среднем,
нет пустой колонки/переполнения; C3 без стенового селектора, покрытие
доступно; C7 материалы/настройки возвращаются, resize/JSON/камера работают.
Build и профильные browser проверки, визуальный просмотр.
Результат: C3/C7 на всю доступную ширину среднего окна. Высота 232,3→128,3
px на 768 (−45%) и 232,3→85,3 на 1024 (−63%); на 390 316,3→228,3.
На 320 сохранена читаемость; большая накладная панель остаётся прежней.
Неприменимый стеновой ряд не рендерится, кровля доступна; смена материала
на комбинацию возвращает половинную ширину и параметры, значения сохранены.
Build с типизацией/worker, 8 responsive групп PASS на 12 окнах.
Профильные C3/C7 на 320/390/768/1024: ширина/высота/подписи, переключение
комбинации, сохранность введённых размеров; стены возвращаются для C4.
Нет ошибок/overflow. Скриншоты final-768/1024-C3 просмотрены.
Отчёты .local/qa/empty-dimensions-before.json, -final.json и
.local/qa/responsive/report.json. Геометрия неизменна, unit не повторялись;
физические телефоны не проверены. HTTP /compact 200; PID 29296.
Следующий шаг: main/резервные копии, затем обратная связь.
