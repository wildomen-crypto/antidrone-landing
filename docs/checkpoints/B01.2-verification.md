# Проверка B01.2

Дата: 3 октября 2026 года (Europe/Moscow).

## Контакты и источники

Действующая https://topengineer.ru/contact прочитана повторно, HTTP 200.
Проверены общая почта и телефон, контакты проектирования, изготовления
и монтажа, график работы, адрес клиентского офиса и реквизиты основного
опубликованного ООО. Значения совпали с разделом 2.1 ТЗ.
Копия исходной страницы — .local/topengineer-contact-B01.2.html.

Контакты определены в config/company.ts; страницу и metadata перевели
на эту конфигурацию. Юридический адрес хранится отдельно от офиса.
Оператор формы, регионы монтажа, SLA и гарантия не выдуманы, пока null.

## Типы и данные

- Версия конфигурации: 1; единицы длины, площади и массы: m/m2/kg.
- Полный каталог с уникальными ID: C1–C8, M1–M8, W1–W3, шесть несущих систем.
- Исходный выпуск включает C1–C5 и C8; C6–C7 относятся к расширению.
- Формы C5–C7 различают варианты и обязательные параметры.
- Контуры C8 ограничены 1–3; видимость viewer отделена от состава заказа.
- Утверждённых сочетаний ещё нет; пустой compatibility не разрешает всё.
- Нет фиктивных шаблонов профилей, нагрузок, тарифов или гарантий.

`tests/configuration/contract.typecheck.ts` проверяет narrowing по форме,
связь ID и key, обязательные размеры, запрет чужих размерных полей,
пустого и избыточного набора контуров, отсутствие viewer-полей в заказе.
Это статическая проверка контракта; runtime-валидация JSON и чисел — B03.1.

## Проверки приложения

- npm run typecheck — успешно.
- npm run build — успешно; / и /icon.svg статические.
- Одноразовая проверка данных через Node: уникальность и полнота ID,
  связь tel/mailto со значениями, неизвестные бизнес-данные и отсутствие
  неутверждённых сочетаний — успешно.
- Собранная версия проверена в Edge при 1440×1000 и 390×844:
  HTTP 200, кириллица, noindex, название в metadata, правильные tel/mailto,
  нет pageerror/console error и горизонтального overflow.
- Скриншоты обоих размеров просмотрены.

Проверочные скрипты и скриншоты находятся в .local и не входят в приложение.
Новых зависимостей не добавлено; package-lock.json не изменён.

## Сохранение и ограничения

Новая версия сохраняется отдельным коммитом; SHA записывается последующим
коммитом журнала. main обновляется после проверок fast-forward.
Для B01.2 сохраняются собственные ZIP и Git bundle; архивы B01.1 остаются.

UI карточек каталога, полный лендинг, калькуляторы, 3D, цены и backend
не реализованы в этом блоке. Следующий блок — B02.1.
