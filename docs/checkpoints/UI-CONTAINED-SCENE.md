# UI-CONTAINED-SCENE

Статус: VERIFIED. База 3960811; предыдущий проверенный код 43a5527.
Ветка ui/contained-scene-icons. Запрос: 3D по ширине основного сайта,
ракурсы компактными иконками прямо на 3D вместо строки под моделью.

Файлы: app/responsive.css, Calculator.tsx, SceneViewControls.tsx, LandingPage.tsx,
responsive/compact browser QA, README/SPEC/STATUS/BLOCKS/QA и эта карточка.
Область — текущий адаптивный /compact. Прежние /wide и / сохранены.

Решение: калькулятор в тех же границах, что .container; прежняя высота
сцены и адаптивные панели. Четыре SVG 20×20 в кнопках 32×32 на нижнем
краю сцены, подписи через aria-label/title, выбранный ракурс выделен.
«Только каркас» сохранён компактным пятым переключателем на сцене.
Геометрия/состояние/JSON не меняются; строка вне сцены удалена.

Критерии: сцена по границам основного контейнера на 320–2560 px;
навигация внутри сцены, не пересекается с настройками; клавиатура/touch,
все четыре ракурса, каркас, resize, JSON, печать и SVG работают.
Typecheck/build и профильные browser QA, визуальный просмотр.
Результат: контейнер совпадает с основным сайтом; ширина сцены на 2 px
меньше из-за боковых границ. Панель иконок 182×40 px внутри сцены, нижний
центр не пересекается с левыми/правыми настройками; пустой строки в сетке
нет. /wide и / сохраняют прежние контролы. Печатная карточка без UI.
Проверено: typecheck, production build/worker PASS; responsive 7 групп,
compact 5 групп PASS. 12 окон 320–2560 px, все C1–C8 на 390/1024/1920.
Canvas/SVG ракурсы и каркас реально меняют картинку, не меняя ведомость;
клавиатура/touch, resize/JSON/печать PASS. Ошибок JS/overflow нет.
Отчёты .local/qa/responsive/report.json и .local/qa/compact/report.json.
Скриншоты calculator-390/1024/1920 просмотрены. Unit/wide повторно не
запускались (геометрия не менялась); физические телефоны не проверены.
