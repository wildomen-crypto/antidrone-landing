Запрос: отдельная версия, на среднем окне панели поверх 3D как на рисунке;
на телефоне сохранить текущую одну колонку. /compact оставить для сравнения.
Файлы: app/overlay/page.tsx, overlay-calculator.css, layout.tsx,

Решение: /overlay наследует compact и получает изолированный CSS от 768 px;
две накладные панели 190 px, ограниченная высота и прокрутка, камера
учитывает реальные границы. Высота сцены как в большом накладном режиме.
Ниже 768 px никаких новых правил, тот же интерфейс и состояние.
Критерии: отдельная ссылка; средние панели внутри сцены, без переполнения;
телефон совпадает с /compact; все формы, resize/JSON/3D/SVG доступны.

отдельный CSS меняет только накладную компоновку от 768 px. Ссылка
«Панели на 3D» добавлена к вариантам. /compact на среднем окне прежний.
Build с типизацией/worker PASS; 5 overlay и 8 responsive групп PASS.

ширина 190 px, границы внутри сцены, toolbar свободен, overflow нет.
Все C1–C8 на 768/1024, варианты/контуры/основания, JSON, resize,
клавиатура и изображения Canvas-ракурсов проверены. SVG резервирует
обе панели на среднем и освобождает поля на телефоне.
