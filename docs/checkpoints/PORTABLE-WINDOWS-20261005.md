Статус: VERIFIED. Дата: 5 октября 2026.

Запрос: архив сайта со всем необходимым для другого неподготовленного ПК.
Цель: Windows 10/11 x64, Node в архиве, standalone-сборка и все изображения,
запуск двойным щелчком, локальная SQLite без переноса прежних заявок/секретов.
Файлы: next.config (standalone только для упаковки), упаковщик/launcher/cmd,
инструкция, README/SPEC/STATUS/BLOCKS. Артефакты только в .local/portable.
Критерии: официальный Node ZIP с проверкой SHA256, лицензии, полный исходник,
готовый сервер/static/public, запуск без установок/npm install и интернета;
проверка распакованной копии в пути с пробелами/кириллицей, формы/3D/изображения,
сохранение/чтение заявки через локальную CLI. Новые данные в папке data.
Занятый 3100 не должен мешать: автоматический свободный локальный порт.
Общий сайт/история GitHub/публичное размещение не изменяются автоматически.
Результат: самостоятельный пакет Topengineer-Windows-x64 с готовой сборкой,
официальным Node 24.14.1, исходниками, лицензиями, START.cmd и LEADS.cmd.
CMD-файлы при упаковке получают CRLF; исключены .env, прежняя БД и частные папки,
которые Next мог включить в standalone по трассировке. DATA_DIR указывает на data
возле launcher. Уведомления/публичный режим выключены для локального запуска.
Упаковщик --repack обновляет исходники/документацию без повторной сборки app.
